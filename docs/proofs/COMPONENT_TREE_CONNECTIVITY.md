# Leaf normalization and connectivity of tree components

Status: mathematical proofs, independently audited by the primary and Astra.
These are structural results for the actual ordinary flip graph. Combined
with the subsequent [connected aggregate extraction](COMPONENT_CONNECTED_AGGREGATE.md),
they prove the full forest-component HRV formula. No Lean implementation is claimed.
Aristotle supplied the general tree argument in its final ordinary-corner
return; [the ledger](../ARISTOTLE.md) records provenance.

## Setting

We work on the ordered vertices 0,...,n-1. A natural edge set G is closed under
subintervals. Its maximal intervals S are strict corners. A state A satisfies
S ⊆ A ⊆ G, and all selected edges point forward. A cover is a selected edge
with no alternative directed path between its endpoints.

A flip at a<b<c replaces ab by bc and retains ac; ab,ac must be covers before,
and ac,bc covers after. If ab,ac are covers before, the other conditions follow:
b cannot reach c, and an alternative a-to-c path after the replacement would
require an alternative a-to-b path before it. The reverse statement is dual.

The interval envelope Env(A) consists of all pairs contained in some selected
edge interval. Flips preserve this envelope, the number of selected edges,
and the partition into undirected connected components.

## A corner cover can be made into a leaf

Suppose lr is a strict corner and is a cover in A. Write N for the selected
out-neighbors of l, and B for A with all outgoing edges of l removed. Since
lr is a maximal natural interval, every member of N lies in (l,r].

We claim that A is connected by flips to

    B ∪ {xr : x ∈ N, x ≠ r} ∪ {lr}.

In particular, lr is the only outgoing edge of l in the final state. Incoming
edges of l are retained; the assertion does not require l to be a source.

The outgoing covers of l are precisely those members of N minimal under
reachability in B. The cover hypothesis makes r minimal. If any other neighbor
remains, we can choose a minimal x≠r: r, being the largest neighbor, cannot
reach a smaller one. The flip (l,x,r) replaces lx by xr. The edge xr is natural
and was absent, since otherwise lr would not have been a cover.

The remaining neighbors still cannot reach r. Any new such path would use xr
and hence reach x, contradicting the chosen minimality of x. We can therefore
repeat. Each step removes exactly one outgoing neighbor other than r and adds
its edge to r. The process terminates at the displayed state, independently
of the choices. No other strict corner is removed, since lx is properly
contained in lr.

Consequently, a complete component has a state in which lr is a cover if and
only if it has a state in which lr is the only outgoing edge of l. Reversing
the order gives the equivalent condition that lr is the only incoming edge
of r in some state. The witnessing states need not agree for different corners.

## Trees with a fixed envelope are connected

**Theorem.** Any two spanning trees T with the same interval envelope H are
connected by actual flips. Thus, when this family is nonempty, it is an entire
tree component in any ordinary ambient diagram admitting its states.

We prove the connectivity assertion by induction on n. For n≤2 it is immediate.
Assume a spanning tree exists. Then H is connected and has a unique maximal
edge 0r incident to 0. Every tree edge is a cover. Leaf normalization gives
0r together with a spanning tree T' on 1,...,n-1. Put H'=H restricted to these
vertices and E=Env(T'). Every maximal edge of H other than 0r remains in T'.

First apply induction inside E. For each v>1 let m_E(v) be the smallest natural
predecessor of v in E. It exists because an edge of T' crosses the cut just
before v, and E is closed under subintervals. The edges

    {(m_E(v),v) : 2 ≤ v ≤ n-1}

form a spanning tree: each vertex other than 1 has one smaller parent, and
iterating parents reaches 1. Every maximal edge ab of E has m_E(b)=a, so this
tree has envelope E. Induction connects T' to it. These flips are valid with
the leaf 0r attached. Original strict corners remaining in T' are maximal
also in E, so none is lost during this normalization.

If r=1, then E=H' already. For r>1, H' is generated by 1r and the maximal
edges of H other than 0r. If 1r belongs to E, we likewise have E=H'. Otherwise,
follow the canonical parent path

    r=p₀ > p₁ > ... > pₜ=1.

For i=1,...,t, use the join flip (0,pᵢ,pᵢ₋₁) to replace pᵢpᵢ₋₁ by 0pᵢ,
retaining 0pᵢ₋₁. Next use (0,1,r) to replace 01 by 1r, retaining 0r. Finally
replace each remaining 0pᵢ, 1≤i<t, by pᵢr using the retained 0r.

Every step stays a tree, so all required cover conditions hold. All introduced
edges lie inside 0r and are natural. Every removed edge other than a temporary
edge at 0 lies properly inside 0r, so it cannot be an original strict corner.
The result is again a leaf at 0 attached to a tree T'' on the remaining
vertices. This tree contains 1r and every other maximal edge of H; hence its
envelope is H'.

Induction inside H' now connects all the leaf states obtained from all starting
trees. This connects the starting trees themselves. Finally, edge count,
undirected connectivity, and envelope are flip invariants. Any state in the
same ambient component is therefore another spanning tree with envelope H,
which proves the entire-component assertion.

## Reachability forced throughout a tree component

Let H be a connected interval-closed graph and let M be its maximal
intervals. The complete tree component with envelope H consists precisely
of the spanning trees of H containing M. We orient every edge forward.

**Theorem.** A pair u<v is reachable in every tree of this component if
and only if M contains a directed path from u to v.

Every vertex has at most one incoming and one outgoing edge in M:
two maximal intervals cannot have the same left or right endpoint.
Thus M is a disjoint union of increasing chains, including isolated
vertices. A path in M belongs to every tree, proving one implication.

For the converse, suppose u and v belong to different chains. Contract
the chains of M in H. The resulting directed graph is strongly connected.
Indeed, if i→j is an edge of H, choose a maximal interval ab containing
ij. The quotient has a return walk

    [j] → [b] = [a] → [i],

using the natural edges jb and ai and omitting steps with equal endpoints.
Its underlying graph is connected, so these return walks prove the claim.

Choose a simple directed quotient path from [v] to [u]. Lift its edges
to H and adjoin M. This is a forest: after contracting the chain trees,
its added edges form a simple path. Extend it to a spanning tree T of H.
Because T contains M, its envelope is H. The unique u–v path in T
traverses every interchain edge of the chosen path backwards. It is
therefore not a directed path from u to v. This proves the theorem.

**Corollary.** Suppose we insert an absent strict corner f=ac into every
tree with envelope H. The inserted edge is redundant in every resulting
state exactly when a and c belong to the same chain of M.

Under this condition the resulting states form a whole unicyclic component.
The new edge cannot participate in a flip because it is redundant. Adding
or deleting it preserves reachability and hence all other cover tests.
Every flip after its deletion stays in the original tree component; no
new edge outside H can be introduced by such a flip, since each introduced
interval lies inside the retained selected interval. Thus insertion and
deletion identify the two whole flip graphs. Their K and E sums agree.

Conversely, deleting a strict corner that is redundant throughout a
connected unicyclic component gives a whole tree component. The theorem
then forces its endpoints to lie on one maximal-interval chain. We have
therefore characterized these inactive unicyclic components.

The primary and independent Astra reviewer audited the quotient-path
proof. A separate exact Rust check enumerated all 1,441 spanning trees
on 2 through 6 ordered vertices, grouped into 64 envelope components;
the intersection of their reachability relations was always Reach(M).

## A tree path can be kept inside its endpoint interval

**Lemma.** Let H be a connected interval-closed graph on an ordered
vertex set V. For s<t in V, there is a spanning tree with envelope H
whose s–t path uses only vertices in V∩[s,t]. Every tree with envelope
H can be connected to such a tree by actual flips.

Let M be the maximal intervals of H. The induced graph H[V∩[s,t]] is
connected: every consecutive pair in V is a natural edge, since some
edge crosses its separating cut and H is interval closed.

Each increasing chain of M meets [s,t] in a connected subchain, possibly
empty. Contract these subchains in the induced graph and choose a simple
path between the classes of s and t. Lift its edges and adjoin all of M.
The resulting graph is a forest: the lifted path joins distinct global
M-chains in succession. Its s–t path lies inside [s,t], because the
intermediate paths within the M-chains do so. Extend this forest to a
spanning tree of H. The path is unchanged, and containing M gives the
required envelope. The tree-connectivity theorem gives the flip path.

The assertion concerns the endpoint tree. It does not require the
normalizing flips to keep the original s–t path or any directed
reachability constraint. That stronger restriction can disconnect the
tree family; see [the four-cycle proof](COMPONENT_FOUR_CYCLE_SWAP.md).

## Scope and use

For forests the theorem applies separately to each fixed undirected block
and that block's own selected-edge envelope. The global envelope alone is
insufficient: an interval in one block may contain an edge from another.

The theorem establishes the tree level of the active-component uniqueness
proposal in [the corner note](COMPONENT_ACTIVE_CORNERS.md). It does not prove
that proposal for states with more edges. To isolate the tree component's
polynomial, first extract the connected aggregate using set-partition inversion,
as proved in [the semantic companion](COMPONENT_CONNECTED_AGGREGATE.md).
Using an unrestricted aggregate coefficient would leave disconnected states
with cycles at the same total number of edges.

The [compatible-lift reduction](COMPONENT_AMBIENT_REDUCTION.md) transports
circular forest components to ordinary ones. Together with that semantic
companion, it now establishes the HRV identity for every circular forest component.

`ComponentSemantics.lean` defines the complete-component sums. The lemmas in
this note are not yet declarations in those files.
