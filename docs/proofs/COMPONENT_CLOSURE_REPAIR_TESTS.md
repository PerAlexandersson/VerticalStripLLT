# Component repair using equal reachability relations

2026-09-28. This note records a sufficient exact test for component
reconstruction after NN. It succeeds on the selected finite fixtures
below. Two proposed restrictions on the target components fail, even
when we retain all free coefficients. A uniform reconstruction theorem
is still missing.

## Equalities available after the NN split

Fix the corner-deletion diagram with natural edges G and prescribed
strict edges S. A state is a selected edge set containing S. If P is its
reachability relation, write H(P) for the Hasse edges. The states having
reachability relation P form the Boolean interval

    H(P) ∪ S ⊆ A ⊆ G ∩ P.                                    (1)

Indeed, every cover relation must be a selected edge, and every selected
edge belongs to the reachability relation. Conversely, the lower bound
already generates P, so adding any of the permitted edges changes no
reachability. All states in (1) have equal K and equal E.

We also allow the fixed adjacent NN swap σ=(a a+1), whenever it sends a
state to a natural state, fixes S as a set, and the two vertices are not
both sinks. This preserves the relative order of the sinks and therefore
K and E. We use no other relabelings and no further target diamonds.

Each equivalence class generated by (1) and this swap contains at most
two reachability relations, P and σP. Each relation has a unique minimal
and maximal state. Hence each class has at most two representatives of
smallest cardinality and at most two of largest cardinality. When both
relations occur, their minimal cardinalities agree, since σ fixes S and
carries H(P) to H(σP).

For a fixed source component, apply the canonical NN split and sum its
signed coefficients over each equivalence class. We seek a linear
combination of complete target components with these same sums. Each
target component contributes a column whose entry is the number of its
states in the indicated equivalence class. Any solution proves the same
component identity for K and E using only the stated equalities.

## Why the extremal representatives do not suffice

It is tempting to allow only target components containing a largest
representative of some class. At the leading cardinality, a class then
contributes an equation involving at most two component coefficients.
This restriction fails. Solving all levels together does not fix it:
some canonical NN images lie outside the span of these columns.

The analogous restriction to components containing a smallest
representative also fails. We record exact failures, rather than
attributing them to arbitrary early choices of free coefficients.

| Source area sequence | NN corner | Maximal restriction fails | Minimal restriction fails |

Masks use the natural edges in lexicographic order; indices are zero-based
in the ordered complete-component enumeration. In each fixture all
maximal corners are prescribed strict, as recorded in the source consumer.
These are exact inconsistent rational systems. Allowing all target
component columns succeeds for every source component tested here.

A filtration can still retain all columns: assign a target component C
the minimum, over states in C, of the largest state cardinality in that
state's equivalence class. This organizes the full linear system, but
its leading equations can involve many states. It supplies no proof
that the system is solvable.

## A valid whole-component reduction

One useful special case does admit an elementary argument. Suppose a
normal edge e is absent and implied by a directed path in every state
of a whole component C. Adding e sends C bijectively onto a whole
component C′, with the same column in the system above.

The added edge is redundant, hence can be neither retained nor exchanged
by an actual flip. The reachability relation, and therefore its cover
relations, are unchanged. Every flip in C therefore lifts. Conversely, a flip
from an image state avoids e and descends to a flip in C; completeness
of C puts its endpoint back in C. This proves both connectedness and
closure of C′. For the inverse statement, suppose e is selected and
redundant throughout C. Every flip in C descends after deleting e.
A flip from a state in the deletion image also lifts: restoring redundant
e preserves its two initial cover tests, so the one-endpoint cover
criterion applies. Completeness of C then supplies the endpoint in the
deletion image. Thus deletion likewise gives a whole component.

The condition throughout the component matters. Adding an edge to a
single state with that reachability does not establish a map of whole
components or justify the failed restrictions above.

## Exact finite evidence

We checked 31 source components in five fixtures:

- all 15 components of the four-vertex complete diagram;
- the two remaining five-vertex components from
  [the overlapping-corner calculation](COMPONENT_OVERLAPPING_CORNERS.md);
- four remaining components in each of the first two larger diagrams
  in the table;
- six remaining components in the final diagram.

Here remaining means connected, non-tree, and containing a state without
a mixed directed cycle. This is a selected list of fixtures, not an
exhaustive enumeration of diagrams through seven vertices.

For every fixture, the component identities have solutions using the
full target component set. The largest target has 32,768 states,
6,931 equivalence classes and 2,639 complete components. Each successful
certificate is checked by recomputing its class sums, then independently
evaluating both K and E with exact arithmetic.

Related Rust: the external `nn_capacity_repair.rs` consumer reuses
`components`, `cover` and `valuations`, and the maintained
`sym_poly_core::sparse_linear_algebra::sparse_rref`. The canonical receipt
is `capacity_minimal_repair.jsonl` under
`/lake-cache/ai-projects/requests/VerticalStripLLT/overlapping-corners/`.
Its `representative_policy` distinguishes the three column restrictions.
The joint solve retains all free parameters; each successful solution is
checked against the original, unreduced equations. Sources and receipts
are frozen with hashes in that directory.

The remaining proof obligation is to show that every canonical NN image
has a whole-component reconstruction, or to construct repairs by a
different local argument. These experiments give no general solvability
or integrality theorem, and do not address all DN or DD recurrences.

## Further tests and a proved unicyclic case

The [unicyclic redundancy lemma](COMPONENT_UNICYCLIC_REDUNDANCY.md)
now proves the minimal-representative property for saturated connected
unicyclic components. Its proof uses whole-component redundant-edge
deletion and tree connectivity; it does not assert the failed property
for arbitrary components.

We also tested how far beyond maximal representatives the component
columns must extend. Define the deficit of a component C to be

    min_(A in C) (max_(B equivalent to A) |B| − |A|).

Deficit zero means that C contains a largest representative of some
equivalence class. The simultaneous exact solve gives:

| Source diagram | Least bound sufficient for every tested source component |
| --- | ---: |
| (0,1,2,3) | 0 |
| (0,1,2,3,3) | 0 |
| (0,1,2,3,4,3) | 1 |
| (0,1,2,3,4,3,2) | 1 |
| (0,1,2,3,4,3,4) | 2 |

In the last fixture, source indices 62 and 70 still give inconsistent
systems at deficit one. All six pass at deficit two, allowing 1,651 of
the 2,639 target components. Thus even a one-edge extension of the
maximal-representative restriction is insufficient. This test does not
establish any universal bound on the deficit.

An exhaustive ordinary area-sequence scan through six vertices, with all
corners strict, tests every NN instance satisfying the terminal gap,
equal initial boundary, and absence of strict heads at the two swapped
vertices. For each instance we retain exactly the connected non-tree
source components containing a mixed-acyclic state. With all target
columns allowed, every such source component passes:

Counts include repetitions when a diagram admits more than one NN move.
All 55 resulting identities have integral coefficients in the returned
