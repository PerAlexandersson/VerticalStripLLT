# Ordinary component proof: Lean integration plan

The complete mathematical source is [the ordinary proof](proofs/COMPONENT_ORDINARY_PROOF.md).
This plan implements its full statements, without a general symmetric-functions
library. Existing aggregate theorems are not component semantic bridges.

## Modules and dependencies

1. `Components/WordRelations.lean`: words `List V`, integer finitely supported
   combinations, the submodule generated by all repeated-letter words and all
   contextual four-word relations. Prove the exact universal property for
   linear functionals vanishing on those generators. This is an additive
   quotient only; it is not yet asserted to be a ring.
2. `Components/WordConjugation.lean`: general ring lemmas for squarefree
   generators and the four-word relation. Prove inverse finite products,
   truncated conjugation and commutation with the sum of letters. These are
   genuine algebraic lemmas with explicit hypotheses, not the component theorem.
3. `Components/WordAlgebra.lean`: concatenation on the word module and its
   descent to the contextual quotient. Prove the algebraic hypotheses in item 2
   in this concrete quotient. Mathlib `RingQuot` is an alternative if the
   additive quotient induces unnecessary instance work; a component functional
   is linear, not a ring homomorphism, in either implementation.
4. Combinatorial interface: compatible-permutation multiplicities of one
   complete ordinary component, the actual-flip four-term pairing, and its
   factorization through item 1. Prove the strict coloring refinement directly.
5. HRV interface: exact alternating-map coefficients, labeled-poset absorption
   and refinement, and the signed mountain-block formula. Identify the same
   component multiplicities on this independently defined side.
6. Finite Cauchy factorization: derive the ordered mountain expansion from
   item 2, pair via item 4, and conclude equality with item 5 for every alphabet.
   Export the full ordinary component theorem and then compatible-lift transport.

The first parallel batch consists of items 1 and 2. They have disjoint files
and no dependence on unimplemented component statements. Items 3--6 remain
necessary; proving the first batch is not a verification of the full theorem.
