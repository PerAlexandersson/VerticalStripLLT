# VerticalStripLLT

Lean formalization of Per Alexandersson and Robin Sulzgruber,
*A combinatorial expansion of vertical-strip LLT polynomials in the basis of
elementary symmetric functions* (arXiv:2004.09198; published 2022).

The first objective is the ordinary, noncircular theorem. The intended initial
model is deliberately narrow: finite-degree coefficient representations for
LLT and elementary-basis expansions, decorated area sequences, the recursive
relations, and the bridge to the coloring definition. A general-purpose
symmetric-functions library is outside the initial scope.

Later projects, including circular vertical-strip LLT polynomials and LLT
cumulants, should depend on this foundation rather than duplicate it.
