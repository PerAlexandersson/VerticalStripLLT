# Review mathematical structure before declaring a draft complete

The first assembled draft compiled cleanly but still presented named results
as bold paragraphs, omitted author metadata, and dispersed the four central
recurrences. The author's review exposed these gaps immediately.

The assembler now preserves semantic theorem/proof environments and rejects
unparsed environments, duplicate labels and missing reference targets.
For future writing passes, also inspect the rendered result hierarchy: every
statement needs a conclusion and explicit hypotheses, the introduction should
explain the proof's dependencies, and the key recurrences should be visible
together. Compare against the actual coauthored draft for authors and retained
applications before finalizing. These checks belong in a future approved
writing-skill revision; they are not new project policy.
