# Keep one current recurrence status map

The recurrence research now spans many proof notes. Statements of what remains
open in an older note can outlive the lemma that closes them, making recovery
and dependency audits slower and risking duplicate work.

At the next consolidation, add one compact status table to docs/README.md:
NN/DN/DD, connectedness, cycle rank, saturation, and links to the current
complete statement. Keep detailed exploratory chronology in the archives.
New proof checkpoints should update that table and link from superseded notes.
This is a maintenance proposal, not a change to the requested proof method.
